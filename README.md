# Лабораторна робота №1 — варіант 012

Аналіз синтетичних 15-хвилинних показників 200 смартлічильників за березень 2024 року. Основний файл для перегляду й захисту — [notebooks/lab01_cleaning.ipynb](notebooks/lab01_cleaning.ipynb). У ньому послідовно наведено генерацію, статистику до очистки, правила й валідацію, порівняння та 10 KPI. Висновки, таблиці й графіки показані безпосередньо під відповідними блоками.

## Файли для здачі

- `notebooks/lab01_cleaning.ipynb` — виконаний R notebook.
- `data/raw/generated_dirty.csv` — синтетичні дані з контрольованими дефектами.
- `data/clean/dataset_clean.csv` — очищена часова сітка.
- `data/tariff_reference.csv` — довідник цін T1/T2 за об’єктами.
- `change_log.csv` — кількість змін для кожного правила очистки.
- `requirements_R.txt` — пакети для повторного запуску.

## Повторний запуск

Встановіть R, Jupyter і пакети `data.table`, `lubridate`, `ggplot2`, `jsonlite`, `IRkernel`. Для реєстрації R kernel один раз виконайте `IRkernel::installspec()`. Відкрийте Jupyter із кореня цього репозиторію, запустіть **Run All** у notebook. Перша кодова клітинка фіксує seed `12012`; повторний запуск формує CSV, `change_log.csv` і додаткові діагностичні файли в `outputs/`.

У березні 2024 року локальна сітка `Europe/Kyiv` має 2972 інтервали на лічильник: 31 березня година 03:00–03:45 пропущена через перехід на літній час. Ціни й вимірювання синтетичні.
